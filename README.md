# 🎓 Student Grades Analysis using Pandas

Analyze and visualize student performance using **Python**, **Pandas**, and **Matplotlib**.  
This project demonstrates data cleaning, score calculation, weighted grade computation, and identifying top performers.

---

## 📂 Project Overview
- Load and clean student grade data  
- Calculate total scores for homework, quizzes, and exams  
- Compute weighted final grades (Homework 20%, Quizzes 30%, Exams 50%)  
- Visualize grade distribution with a histogram  
- Display top 5 performers and a summary report
